QR Snip - Test & Verification Page

Test the QR Snip Chrome extension right on this page. Click the extension icon or press Alt+Shift+Q, then drag a box over either QR code.

1. URL QR Code

Encodes https://github.com/google
Expected: Bold domain + Open link button

2. Plain Text QR Code

Encodes plain text message
Expected: Text content + Copy button

Testing Steps:

  1. In Chrome, navigate to chrome://extensions, enable Developer mode, and click Load unpacked. Select this extension directory (d:\projects).
  2. Open this test.html file in Chrome (or any web page containing a QR code).
  3. Click the QR Snip extension toolbar icon or press Alt+Shift+Q.
  4. Drag a selection rectangle over the QR code to decode it.
  5. Verify that for URLs, the domain is bolded and clicking Open link opens the URL in a new tab.
  6. Verify that for plain text, the Copy button copies the text and shows "Copied!".
  7. Press Esc anytime to cancel selection or close the popup.
